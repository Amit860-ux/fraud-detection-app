# Fraud Detection App

A machine learning project that detects fraudulent transactions.

## Features
- Data analysis and model training (`analysis_model.ipynb`)
- Saved ML pipeline (`fraud_detection_pipeline.pkl`)
- Prediction script (`fraud_detection.py`)

## Tech Stack
Python, pandas, scikit-learn, Jupyter Notebook

## Dataset
The dataset (`AIML Dataset.csv`, ~400 MB) is too large for GitHub.
Download it from <your link here> and place it in the project root.

## How to Run
1. Clone the repo:
   git clone https://github.com/Amit860-ux/fraud-detection-app.git
2. Install dependencies:
   pip install -r requirements.txt
3. Run:
   python fraud_detection.py
